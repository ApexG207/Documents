# Contributing to MatIQ

MatIQ is proprietary commercial software. Contributions are accepted only under the MatIQ Contributor License Agreement (`CONTRIBUTOR_LICENSE_AGREEMENT.md`) or another written agreement approved by Apex Governance Group. Submission of code does not make MatIQ open source and does not grant contributors a right to redistribute MatIQ.

All work must reference a GitHub issue, use a feature branch, pass build and security checks, and receive review before production. Never commit credentials, `.env` files, real minor data, protected athlete records, videos, exports, or incident evidence. Use synthetic data in development and redact logs and screenshots.

Commit messages should state the outcome. Pull requests must include scope, risks, tests, privacy impact, rollback, and screenshots only when they contain synthetic data.

Contributors must confirm they have authority to contribute the work and must not submit third-party code, confidential information, employer-owned material, or other content unless its license and provenance permit incorporation into MatIQ.
